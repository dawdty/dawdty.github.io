# edmund hattle — website

Plain static HTML site served via GitHub Pages at <https://www.edwor.my/>.

This repository contains only hand-written HTML, CSS, and assets. No build step, no framework.

- `CNAME` — custom domain (`www.edwor.my`)
- `.nojekyll` — tells GitHub Pages to skip Jekyll processing

## Deploying

Push to `main`. GitHub Pages serves the branch root directly.
